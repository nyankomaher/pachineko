# 分析画面 仕様書

## 概要

分析画面（`/analysis/`）は UC2（遊戯後の分析）のうち、様々な軸で実績を集計・可視化する役割を担う。実績一覧画面（`specs/records-list.md`）が個々の実績の一覧・閲覧に特化するのに対し、本画面は複数の実績を横断した集計・比較を目的とする。

## 対象デバイス・レイアウト方針

- 分析は PC 閲覧を同等に重視するため、レスポンシブ対応必須。グラフや集計テーブルが横に広い場合はPC幅を活かしたレイアウトとする。
- グラフ表示には PrimeVue の `Chart`（Chart.js ラッパー）を使用する（`CLAUDE.md` の方針どおり）。

## 画面構成

### 集計軸の選択

以下の軸から選択して集計する。

| 軸 | 集計単位 |
|---|---|
| 月別 | 実績の日付を月単位に丸めて集計 |
| 日別 | 実績の日付単位で集計 |
| 店舗別 | 店舗IDで集計 |
| 機種別 | 機種IDで集計 |
| 台別 | 店舗ID + 機種ID + 台番号の組み合わせで集計（同じ機種でも台番号が異なれば別集計とする） |

軸は単一選択とし、選択した軸ごとにグラフと集計テーブルを表示する。

### 集計対象期間の絞り込み

期間（開始日〜終了日）、店舗、機種によるフィルタを提供し、集計対象の実績を絞り込めるようにする。

### 集計内容

選択した軸の各グループごとに、実績テーブルの「総〜」項目を合算・平均した以下の値を表示する。

- 実績件数
- 投資金額（合計）
- 回転数（合計）
- 1000円あたり回転数（グループ内の投資金額合計・回転数合計から算出。個々の実績の1000円あたり回転数の単純平均ではなく、合計値から算出することで期間の長さに左右されない値にする）
- 獲得玉数（合計）
- ST当選数・通常当選数・チャージ当選数（合計）

### グラフ

- 軸ごとのグループを横軸、1000円あたり回転数または投資金額を縦軸とした棒グラフを基本とする。
- 具体的なグラフの種類・組み合わせ（複数指標の切り替え等）は実装フェーズで確定する。

### 集計テーブル

グラフと合わせて、グループごとの集計値を表形式（`DataTable`）でも表示し、グラフでは読み取りにくい詳細な数値を確認できるようにする。

## データアクセス

- Dexie から実績テーブル（および必要に応じて店舗・機種テーブル）を取得し、選択軸・フィルタ条件に応じて集計する。件数が多い場合の集計処理のパフォーマンスは実装フェーズで検証する。

## スコープ外・今後の検討事項

- 区間実績単位（実績内の個々の区間）の分析は対象外とし、実績単位の集計に限定する。
- 複数軸を組み合わせた集計（例: 店舗×機種のクロス集計）は本仕様では扱わない。
- グラフの具体的な配色・デザインは実装フェーズで別途提案する。
