# 設定画面 仕様書

## 概要

設定画面（`/settings/`）は UC3（エクスポート）・UC4（インポート）を担う画面で、記録したデータをファイルとして書き出し、また書き出したファイルを読み込んで復元する導線を提供する。

## 画面構成

### エクスポート

- 「エクスポート」ボタンを押下すると、IndexedDB（店舗・機種・実績・区間実績の全テーブル）の内容をファイルとしてダウンロードする。
- ファイル形式は JSON とし、店舗・機種・実績・区間実績の各テーブルの全レコードをテーブル名をキーにしたオブジェクトとして書き出す（テーブル間の整合性を保つため、AutoIncrement の ID をそのまま含める）。
- ファイル名には日時を含める（例: `pachineko-export-20260810.json`）。

### インポート

- 「インポート」ボタンでファイル選択ダイアログを開き、エクスポートされたJSONファイルを選択する。
- インポート内容の取り込み方針（既存データとの関係）を選択させる。
  - 既存データをすべて削除してから取り込む（置き換え）
  - 既存データに追加する（ID の重複が発生しうるため、実装フェーズで ID の再採番方針を確定する）
- インポート実行前に確認ダイアログを表示する（特に「置き換え」は既存データを削除する不可逆な操作のため）。
- インポート中に記録中セッションが存在する場合の扱い（インポートを禁止する、またはセッションを破棄してから実行する）は実装フェーズで確定する。

### バリデーション

- インポートするファイルが期待するスキーマ（テーブル名・フィールド構成）と一致するか検証し、不正なファイルの場合はエラーメッセージを表示してインポートを中止する。

## データアクセス

- エクスポート: Dexie の各テーブルを全件取得し、JSONへシリアライズする。
- インポート: JSONをパースし、選択された取り込み方針に従って Dexie の各テーブルへ書き込む（「置き換え」の場合は既存テーブルの全件削除後に書き込む）。

## スコープ外・今後の検討事項

- 部分的なエクスポート（期間指定や店舗・機種を絞ったエクスポート）は本仕様では扱わない。全件エクスポートのみとする。
- 他アプリ・他フォーマット（CSV等）とのデータ互換性は考慮しない。
- インポート時のID重複の再採番方針の詳細設計（上述）。
