# 実績一覧画面 仕様書

## 概要

実績一覧画面は UC2（遊戯後の分析）の入口の一つで、記録済みの**実績**（1台の遊戯開始〜終了の記録）を一覧表示する。ここでは個々の実績の閲覧・選択のみを担い、月別・日別などの軸による集計は「分析」画面の役割とする（本仕様のスコープ外）。

## 対象デバイス・レイアウト方針

- 分析（UC2）は PC 閲覧も同等に重視するため、レスポンシブ対応必須。
- 表形式のデータを扱うため、PrimeVue の `DataTable` を採用する（`CLAUDE.md` の方針どおり）。

## 画面構成

### 一覧表示

`DataTable` で以下の列を表示する（実績テーブルのフィールドに対応）。

| 列 | 内容 |
|---|---|
| 日付 | 実績の日付 |
| 店舗 | 店舗ID から解決した店舗名 |
| 機種 | 機種ID から解決した機種名 |
| 台番号 | 実績テーブルの台番号 |
| 投資金額 | 総投資金額（画面表示上は「総」を付けない。`CLAUDE.md` 用語定義に準拠） |
| 回転数 | 総回転数 |
| 1000円あたり回転数 | 総1000円あたり回転数 |

- 店舗名・機種名は店舗ID/機種IDをキーに店舗テーブル・機種テーブルを参照して解決する（結合表示）。
- 初期ソート順は日付の降順（新しい実績が上）。
- 各行をタップ/クリックすると実績詳細画面（`/records/[recordId]`）に遷移する。

### 記録中の実績の扱い

`CLAUDE.md` の業務フロー上、実績は記録開始時点（区間実績の記録前）で実績テーブルに1行が作成される。そのため、一覧には**記録中セッションに紐づく実績**（まだ区間実績が0件、または記録が進行中の実績）も表示されうる。

- 記録中セッションが存在し、かつそのセッションが対象とする実績IDと一覧の行の実績IDが一致する場合、その行に「記録中」であることが分かるバッジ等を表示する。
- 集計列（投資金額・回転数・1000円あたり回転数）は、その時点までに記録済みの区間実績を元にした値を表示する（区間実績が0件の場合は 0 または未記録として表示）。

### フィルタ・検索

- 店舗・機種によるフィルタ（`DataTable` のフィルタ機能を利用）を提供する。詳細な絞り込み・軸別集計は分析画面の役割とし、本画面では簡易フィルタに留める。

## データアクセス

- 一覧表示用のデータ取得は Dexie の実績テーブル・店舗テーブル・機種テーブルへのクエリで行う。件数が増えた場合のページング方針（`DataTable` の内蔵ページネーション利用等）は実装フェーズで確定する。

## スコープ外・今後の検討事項

- 月別・日別・台別などの軸による集計表示は「分析」画面（`specs/analysis.md`）の責務とする。
- 一覧からの実績の編集・削除は行わない（実績詳細画面に遷移してから行う）。
- 大量データ時の仮想スクロール／サーバーサイドページング相当の最適化は、必要になった時点で別途検討する。
